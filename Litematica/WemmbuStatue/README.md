# Wemmbu-inspired Mace & Shield Statue

A 75-block-tall Litematica build generator for Minecraft Java.

## Contents
- `make_statue.py` — generates the schematic
- Vanilla Minecraft block textures only; no resource pack required
- Netherite-style armor and helmet, shield, and a chunky 3D mace
- No Elytra

The shield design is an original purple/cyan interpretation, not an official extracted Wemmbu shield texture.

## Generate the .litematic file
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `python -m pip install litemapy`.
4. Run `python make_statue.py`.
5. The file `Wemmbu_Mace_Shield_75.litematic` will appear in the same folder.

Move the generated file into your Minecraft `schematics` folder and load it with Litematica.
