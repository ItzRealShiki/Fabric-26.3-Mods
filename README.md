# Fabric 26.3 Mods

A collection of independent Fabric client-side mods for Minecraft Java Edition, maintained by **ItzRealShiki**.

## Projects

- **CoreMod** — client utility menu and configurable quick-command slots.
- **SimpleLitematica** — schematic preview and building helper.
- **LifestealCore client mod** — server-controlled FastPlace and FastBreak support for compatible servers.

Each project has its own build configuration. See its directory for requirements and build instructions.

## Build requirements

- Java 25 for Minecraft 26.3 projects.
- Fabric Loader and Fabric API versions specified by each mod's metadata/build configuration.
- Use the Gradle wrapper if present; otherwise use the Gradle version specified by the project's workflow.

## Downloads

Successful CI builds and published JARs are available from the repository's **Releases** page. Always choose a build matching your Minecraft version.
